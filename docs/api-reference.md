## Overview
The Salary‑Predictor API provides a single inference endpoint that accepts job‑related attributes and returns a salary prediction generated by a pre‑trained RandomForestRegressor model.

## Endpoints
### `POST` /predict
Predict salary based on user-provided job features

**Parameters / Payload:**
JSON body with fields matching model features (e.g., "job_title", "location", "years_experience", etc.)

**Response:**
```json
JSON containing predicted salary and optional confidence interval
```

| Code | Meaning |
| :--- | :--- |

| `500` | Internal Server Error – model loading or prediction failure |
