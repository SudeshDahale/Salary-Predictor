# Salary Predictor API Reference

**Base URL:** `http://localhost:5000`  
**Authentication:** None

## Overview
The Salary Predictor provides a RESTful API to obtain salary predictions based on job position features. Implemented in Python (backend/app.py), the service loads a pre‑trained Random Forest model (models/rf_regressor.pkl) and returns an estimated salary.

## Endpoints
### `POST` /predict
Accepts job‑related features and returns a salary prediction generated by the Random Forest regressor.

**Parameters / Payload:**
JSON object in request body. Required keys correspond to the model’s features (e.g., "position", "company", "years_experience", "education_level"). All values must be of type string or numeric as appropriate.

**Response:**
```json
JSON object with field "predicted_salary" (float) representing the estimated annual salary.
```

---
### `GET` /health
Simple health‑check endpoint that confirms the service is running.

**Parameters / Payload:**
None

**Response:**
```json
JSON object with key "status" set to "OK".
```

---


## Error Codes
| Code | Meaning |
| :--- | :--- |
| `400` | Bad Request – missing or malformed input parameters. |
| `404` | Not Found – the requested endpoint does not exist. |
| `500` | Internal Server Error – unexpected error during model loading or prediction. |
